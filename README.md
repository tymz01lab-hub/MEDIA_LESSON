# MEDIA_LESSON

웹캠 손 추적으로 그리는 인터랙티브 샌드아트. 현재 관리 기준 파일은 `index.html`이며, 모래 효과음까지 추가한 v6 버전입니다.

## 실행

`index.html`을 내려받아 Chrome에서 열고 카메라 권한을 허용합니다. 카메라 접근이 제한된 환경에서는 localhost 또는 HTTPS에서 실행하세요. MediaPipe 모듈과 손·얼굴 인식 모델을 불러올 때 인터넷 연결이 필요합니다. 별도 빌드나 음원 파일은 필요하지 않습니다.

## 조작

- **손 인식:** 웹캠을 켜고 손 전체를 보여준 뒤, 엄지·검지를 붙여 검지 끝으로 모래를 그립니다. 손가락을 떼면 멈춥니다.
- **검지 끝으로 바로 그리기:** 그리기 메뉴에서 선택하면 핀치 없이 그립니다.
- **마우스 테스트:** 입력 메뉴에서 선택하고 모래판을 누른 채 드래그합니다.
- **모래 고르기:** 그린 자국을 지우고 표면을 초기화합니다.
- **효과음:** 그리는 움직임에 맞춰 모래 마찰음을 생성합니다. 멈추거나 손을 떼면 사라집니다. 브라우저 오디오 활성화를 위해 먼저 웹캠 버튼이나 화면을 클릭하세요.

웹캠·손 스켈레톤·기존 얼굴 미리보기를 유지합니다. 웹캠 영상은 브라우저 안에서 처리하며 업로드하거나 녹화하지 않습니다.

## 현재 검증

- JavaScript 문법 검사 통과.
- Headless Chrome: 마우스 그리기, 자국 유지, 모래 초기화 확인.
- Chrome: Web Audio 초기화와 오디오 실행 상태 확인.
- 실제 웹캠 손 인식과 스피커 청취는 현장 확인 필요.

## 작업 범위

한 단계씩 수정하고 현재 단계의 변경과 테스트 결과만 보고합니다. 현재 기능과 구조를 유지하며 요청하지 않은 기능은 추가하지 않습니다.
